# Linkz 本地协议兼容服务端

最新入口：根目录 `开始游玩.cmd` / `游玩说明.md` / `交接-继续本地重建.md`。当前为可体验的本地重建版本，完整玩法尚未覆盖。

当前开发阶段为离线打磨，暂不启动游戏验证。新增源码尚未加载到正式服务，待用户允许后统一验证；此前的客户端实测结果仅属于此前版本。

## 启动

在项目根目录执行：

```powershell
python -X utf8 server/linkz_server.py --public-base http://10.0.2.2:3000 --asset-root assets-restored-all
python -X utf8 -m unittest discover -s server -v
python -X utf8 tools/check_offline.py
```

默认仅监听 `127.0.0.1:3000`；存档 `runtime/linkz.sqlite3`。系统 Python 3.10，无第三方运行依赖。恢复资源的工具需要 `.venv` 内 UnityPy，正常游玩不用再次恢复。

## 已接通的主要循环

普通成长捕捉：5 石一次，四种成长兽等概率；Link 捕捉：300 点一次，三种幼年兽等概率。支持 1/10 次，服务端校验余额和容量，失败批次回滚，原请求重试不重复扣费。050002.itemCount 是客户端持有余额，价格由服务端计算。普通抽取重启后应使用新的请求，不能用教学固定收据重放策略。

`normal-world.json` 的敌阵/掉落是重建配置；原 master 提供解锁、体力、波数与首通。未配置关卡保持锁定。仓库等级 0 的施工不提供容量，140010 真正完工后才更新容量。

HTTP/1.1 与连接队列 128 用于承接 Unity 启动目录并发。客户端断开闲置连接不输出异常堆栈。`/health` 只报告服务身份、配置关卡数和资源是否配置，不能代替实机游玩验收。
