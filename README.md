# Digimon Linkz 本地重建

基于原 Android 客户端协议开发的本地兼容服务端、中文配置和分析工具。此仓库用于交付自建源码与技术文档；游戏客户端、资源包、原版主数据和个人存档另行保留。

## 当前状态

项目处于离线打磨阶段。服务端包含教学、普通战斗、捕捉、农场、培养、进化、研究孵化、任务礼物与芯片等协议实现；部分数值与掉落采用配置中明确说明的本地重建规则。联机、竞技场、充值和完整原版功能尚未恢复。

此前版本有原客户端游玩证据。后续新增实现仍需统一游戏验收，不能把协议回归或资源检查视为当前版本游戏内通过。批次记录见 [离线打磨记录](research/离线打磨-20261001.md)，验收范围见 [统一验证清单](research/统一游戏验证清单-20261001.md)。公开源码交付不会启动游戏、模拟器或重载已有正式服务。

## 环境与外部输入

- Python 3.10 或更新版本；服务端只依赖标准库。
- 原版主数据和客户端参考源码需要独立准备，目录与来源见 [外部输入说明](docs/external-inputs.md)。协议测试也需要这些输入，单独克隆此仓库不能直接开始游戏。
- 客户端资源恢复及 APK 分析工具有可选依赖，包括 UnityPy、androguard、cryptography、capstone、pyelftools、loguru；只运行服务端不需要安装这些库。具体工具依赖与路径以脚本为准。
- APK、资源缓存、Android SDK/AVD、签名密钥及个人账号存档均不包含在公开仓库中。

## 服务端与离线检查

补齐外部输入后，在项目根目录执行：

```powershell
# 临时数据库协议回归；不会启动 Android 游戏。
python -X utf8 -m unittest discover -s server -v

# 需要本地资源、APK及审计输入的完整离线检查。
python -X utf8 tools/check_offline.py

# 仅静态/资源检查，不执行协议回归。
python -X utf8 tools/check_offline.py --skip-tests
```

需要人工启动服务时使用：

```powershell
python -X utf8 server/linkz_server.py --public-base http://10.0.2.2:3000 --asset-root assets-restored-all
```

`10.0.2.2` 是 Android 模拟器访问宿主机的地址。服务默认面向本地使用，未经公网部署与安全验证。已有服务需显式重载才会使用新源码；启动脚本可能复用旧进程。

## 目录

| 路径 | 内容 |
| --- | --- |
| `server/` | 标准库服务端、玩法配置、中文数据和临时数据库回归 |
| `tools/` | 离线审计、资源恢复、APK修补及本地启动脚本 |
| `research/` | 选定的实现规则、协议核对及待验收技术文档 |
| `docs/` | 公开交付范围与外部输入说明 |

详细协议和本地规则见 [服务端说明](server/README.md)。部分历史证据、交接文件和日志只保存在本地，公开仓库中的引用不表示这些文件已随源码上传。

## 数据与来源

正式账号数据库、缓存版本记录和 APK 签名密钥应独立备份。新设备不要通过测试夹具伪造正式进度，也不要用新签名覆盖旧客户端。部分工具仍保留原开发机路径，使用前需要按本机环境核对。
